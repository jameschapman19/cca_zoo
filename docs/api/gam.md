# cca_zoo.gam

Spline-based nonlinear CCA methods — generalized additive models (`GAMCCA`) and multivariate
adaptive regression splines (`MARSCCA`) — fit by joint trust-region Newton-CG solves
(P-IRLS-style). Built entirely on scikit-learn's own `SplineTransformer` and
`scipy.optimize` — no optional dependency required.
