# cca_zoo.gam

Spline-based nonlinear CCA methods: generalized additive models with `mgcv`-style P-spline
smooths (`GAMCCA`) and multivariate adaptive regression splines in the style of `earth`
(`MARSCCA`). Both fit every view jointly by a closed-form penalised eigenproblem. Built on
scikit-learn's `SplineTransformer` and SciPy — no optional dependency required.
