# cca_zoo.isotonic

Monotonic-additive-model (isotonic) nonlinear CCA methods, fit by functional gradient
boosting (`TreeCCA`'s recipe) with an additive, per-feature structure (`GAMCCA`'s recipe).
Built entirely on scikit-learn's own `IsotonicRegression` — no optional dependency required.
